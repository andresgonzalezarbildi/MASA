# Licencia y atribución de los datos alimentarios

La biblioteca de alimentos distribuida con M.A.S.A. fue elaborada a partir de **OpenNutrition Foods** y adaptada para su utilización dentro de la aplicación, incluyendo normalización de nombres, unidades y estructura de búsqueda.

Fuente original: https://www.opennutrition.app/

OpenNutrition Foods se encuentra disponible bajo la **Open Database License 1.0 (ODbL)**. Los derechos sobre los contenidos individuales de la base se ofrecen bajo una versión modificada de la Database Contents License (DbCL), según la documentación del conjunto de datos original.

- ODbL 1.0: https://opendatacommons.org/licenses/odbl/1-0/
- DbCL 1.0: https://opendatacommons.org/licenses/dbcl/1-0/
- Descarga y condiciones de OpenNutrition Foods: https://www.opennutrition.app/download

Partes de OpenNutrition Foods incorporan información de **Open Food Facts**. Cuando corresponde, se mantiene la atribución a **(c) Open Food Facts contributors**:

- https://world.openfoodfacts.org/

La base derivada incluida en este proyecto se distribuye manteniendo la atribución y las condiciones aplicables de la fuente original.

Además del catálogo incluido, el lector de códigos consulta en tiempo real la API pública de **Open Food Facts**. Los productos importados conservan el código, la fuente y el enlace al registro original para facilitar su revisión.

## Limitaciones

Los valores nutricionales son estimaciones y pueden variar según la marca, el método de preparación y la porción real. M.A.S.A. utiliza estos datos como referencia para estimar el consumo energético y recalibrar el modelo de evolución del peso. No constituyen información clínica ni sustituyen el etiquetado del producto o una evaluación profesional individual.
